# Bundled license texts

Source: [SPDX License List Data](https://github.com/spdx/license-list-data/tree/main/text),
retrieved on 2026-10-04 for the identifiers accepted by `cargo-generate.toml`.
Only year and copyright-owner placeholders were replaced with Liquid variables.

The pre-generation hook selects one text and removes this directory from the
temporary template copy. Generation never fetches license text over the network.
